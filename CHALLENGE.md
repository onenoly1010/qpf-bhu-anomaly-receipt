# How to challenge this receipt

This package reproduces audit *labels*, not a Planck likelihood.

A valid challenge names one frozen assumption or cell and replaces it
with a hashed alternative. Examples:

- θ_cut is independently derived from r_S without using C(θ)
  → supply the derivation and a new WHICH_VERSION
- C₂ is computed from a registered W(ℓ)
  → supply the transfer function and normalization
- S1–S7 can be unlocked
  → supply c_s²(ρ) through w → -1 in this lineage

Invalid challenges:

- importing LQC k_L, DSI, EPRL, or LQG entropy-γ
- treating a pre-existing CMB feature as a BHU prediction
- claiming the hypothesis is RULED OUT (this receipt says NOT ESTABLISHED)
- claiming independent scientific verification because this script passed

Not claimed by this package: publication, stranger reproduction,
USED / VALUED / DEPENDENT.
